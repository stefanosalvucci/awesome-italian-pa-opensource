# Contributing to Awesome Italian PA Dev

Thanks for wanting to contribute! This list aims to be the most comprehensive collection of open-source tools for Italian Public Administration integrations.

## Adding a Resource

### Via Pull Request

1. Fork the repository
2. Add your resource to the appropriate section in `README.md`
3. Use the following format:
   ```
   - [author/repo-name](https://github.com/author/repo-name) — Short description in English. `Language`
   ```
4. Submit a PR

### Via Issue

Don't want to open a PR? [Open an issue](../../issues/new?template=add-resource.md) using the "Add Resource" template.

### Checklist

Before submitting, verify that:

- [ ] The link is working and points to a public repository
- [ ] The description is in English and concise (one line)
- [ ] The resource is placed in the correct category
- [ ] The language/framework tag is included after the description
- [ ] The resource is not already listed
- [ ] If the project is unmaintained (no commits in 2+ years), add `⚠️ *unmaintained*` at the end

### What qualifies

- Open-source libraries, SDKs, and tools
- Must be related to Italian PA services (SPID, CIE, Fattura Elettronica, PEC, ANPR, pagoPA, etc.)
- Any programming language
- Both actively maintained and historical/archived projects are welcome (mark unmaintained ones)

### What doesn't qualify

- Paid SaaS products or closed-source tools
- Generic EU-wide tools not specific to Italian PA
- Tutorials, blog posts, or videos (this is a tools list)
- Forks with no meaningful changes from the upstream repo

## Updating Existing Entries

If a project has changed status (e.g., became unmaintained, moved to a new URL, changed name), feel free to open a PR to update it.

## Code of Conduct

Be respectful and constructive. This is a community resource.
